## 개요

Claude API를 활용해 네이버 고객 리뷰에 대한 답글을 자동 생성하는 독립 웹앱.  
리뷰 붙여넣기 → 답글 생성 → 복사 → 네이버에 붙여넣기 워크플로우를 지원한다.

## API 엔드포인트

### POST /api/generate

리뷰 텍스트를 받아 Claude API로 답글을 생성하고, 히스토리에 저장한다.

**Request body:**
```json
{
  "review": "리뷰 원문 텍스트",
  "customGuide": "커스텀 지침 (선택)"
}
```

**Response:**
```json
{
  "reply": "생성된 답글 텍스트",
  "sentiment": "positive | negative | neutral",
  "id": "uuid"
}
```

**에러:** 400 (리뷰 없음), 500 (Claude API 실패)

---

### GET /api/history

저장된 히스토리 전체를 최신순으로 반환한다. 최대 20건.

**Response:**
```json
[
  {
    "id": "uuid",
    "createdAt": "2026-06-29T10:00:00",
    "review": "리뷰 원문...",
    "reply": "생성된 답글...",
    "sentiment": "negative",
    "customGuide": ""
  }
]
```

---

### DELETE /api/history

히스토리 전체 삭제.

## Claude 프롬프트 설계

### 시스템 프롬프트

```
당신은 네이버 스마트스토어 고객 리뷰에 답글을 작성하는 CS 전문가입니다.
다음 원칙을 따릅니다:
- 공식적이고 정중한 어조 유지
- 답글 길이: 3~5문장
- 네이버 리뷰 답글 형식에 맞게 작성
- 브랜드명: 캐치웰

[커스텀 지침이 있을 경우 이 아래에 추가]
```

### 감정 분기 로직

리뷰 텍스트를 Claude에 전달할 때 감정 분류를 함께 요청한다.

| 감정 | 답글 방향 |
|------|-----------|
| 긍정 | 감사 인사 + 브랜드 재방문 유도 |
| 부정 | 공감 + 사과 + 구체적 해결책 또는 문의 안내 |
| 중립 | 감사 + 추가 문의 유도 |

Claude 응답 형식 (JSON):
```json
{
  "sentiment": "positive | negative | neutral",
  "reply": "답글 텍스트"
}
```

## 히스토리 데이터 구조

`data/history.json`:
```json
[
  {
    "id": "550e8400-...",
    "createdAt": "2026-06-29T10:00:00.000Z",
    "review": "리뷰 원문",
    "reply": "생성된 답글",
    "sentiment": "negative",
    "customGuide": "커스텀 지침"

```

- 최대 100건 유지 (초과 시 오래된 것부터 삭제)
- UI에서는 최근 20건만 표시

시스템 개요 및 차이점

📦 협찬/샘플 출고관리

  • 담당자가 요청 리스트 업로드
  • 팀장 승인 단계 있음
  • 승인 후 출고요청서 다운로드
  • CJ택배 엑셀로 출고완료 처리
  • 업로드 시 플로우(Flow) 메시지 자동 발송

📸 포토이벤트 출고관리

  • 담당자가 요청 리스트 업로드
  • 승인 단계 없음 (바로 출고 가능)
  • 출고리스트 다운로드
  • CJ택배 엑셀로 출고완료 처리
  • 주문번호 중복 자동 차단

⚠ 두 시스템 모두 사이드바 → 출고/반품/교환 관리 메뉴에 있습니다.
⚠ 엑셀 파일은 .xlsx / .xls 형식만 업로드 가능합니다. (5MB 이하)

단계별 사용법

1
요청 리스트 엑셀 업로드 담당자

사이드바에서 협찬/샘플 출고 관리 → 요청 리스트 메뉴를 클릭합니다.
"요청 리스트 업로드" 영역에서 엑셀 파일을 선택하고 [xlsx 파일 업로드] 버튼을 클릭합니다.
업로드 완료 시 플로우(Flow) 메시지가 팀장에게 자동으로 발송됩니다.

2
팀장 승인 팀장

플로우 메시지 수신 후 시스템에 접속합니다.
요청 리스트 메뉴에서 승인할 항목의 체크박스를 선택합니다.
[✔ 승인하기] 버튼 클릭 → 확인 → 항목이 승인 완료 탭으로 이동합니다.
※ 승인하기 버튼은 팀장 계정에만 표시됩니다.

3
출고요청서 다운로드 담당자

승인 완료 메뉴로 이동합니다.
[출고요청서 엑셀 다운로드] 버튼을 클릭하면 CJ택배 접수용 양식으로 다운로드됩니다.
이 파일을 CJ택배 사이트에 업로드하여 택배를 접수합니다.

4
CJ택배 배송완료 엑셀 업로드 담당자

CJ택배에서 발송고객_일별_배달상세 엑셀을 다운로드합니다.
승인 완료 메뉴의 "택배 접수완료 처리" 영역에서 해당 파일을 선택하고
[엑셀 업로드 → 출고완료] 버튼을 클릭합니다.
전화번호를 기준으로 자동 매칭되어 송장번호 등록 및 출고완료 처리됩니다.

5
출고완료 조회 담당자

출고 완료 메뉴에서 기간별로 처리된 내역을 조회하고 엑셀로 다운로드할 수 있습니다.

단계별 사용법

1
요청 리스트 엑셀 업로드 담당자

사이드바에서 포토이벤트 출고 관리 → 요청 리스트 등록 메뉴를 클릭합니다.
"요청 리스트 업로드" 영역에서 엑셀 파일을 선택하고 [xlsx 파일 업로드] 버튼을 클릭합니다.
주문번호가 동일한 건은 중복으로 판단하여 자동으로 건너뜁니다.

2
출고리스트 다운로드 담당자

[출고리스트 엑셀 다운로드] 버튼을 클릭하면 현재 처리 중인 전체 건을 CJ택배 접수용 양식으로 다운로드합니다.
이 파일을 CJ택배 사이트에 업로드하여 택배를 접수합니다.

3
CJ택배 배송완료 엑셀 업로드 담당자

CJ택배에서 발송고객_일별_배달상세 엑셀을 다운로드합니다.
"택배 접수완료 처리" 영역에서 해당 파일을 선택하고 [엑셀 업로드 → 출고완료] 버튼을 클릭합니다.
전화번호를 기준으로 자동 매칭되어 송장번호 등록 및 출고완료 처리됩니다.

4
출고완료 조회 담당자

포토이벤트 출고 완료 메뉴에서 기간별로 처리된 내역을 조회하고 엑셀로 다운로드할 수 있습니다.

엑셀 파일 형식

📦 협찬/샘플 요청 리스트 엑셀 (업로드용)

1행=안내문, 2행=헤더, 3행~=데이터 / A열(등록번호)이 비어있는 행만 신규 등록됩니다.

열 항목명 설명
A등록번호시스템 등록 후 자동 기입 — 비워두세요
B요청날짜출고 요청 날짜 (YYYY-MM-DD)
C제품명 *필수협찬/샘플 제품 모델명
D악세서리 추가추가 동봉 악세서리명
E수량출고 수량 (기본값: 1)
F사유협찬/샘플 출고 사유
G인플루언서명인플루언서 채널명 또는 본명
H업체명소속 업체명
I수령자명 *필수택배 수령인 이름
J송장번호비워두세요 (시스템이 자동 등록)
K핸드폰 *필수수령인 휴대폰 번호 (출고완료 매칭 기준)
L일반전화수령인 일반 전화번호
M주소 *필수배송 주소 (전체 주소)
N배송메시지배송 시 전달 메시지

📸 포토이벤트 요청 리스트 엑셀 (업로드용)

1행=헤더, 2행~=데이터 / 주문번호가 동일한 건은 자동으로 건너뜁니다.

열 항목명 설명
A품목명 *필수발송 사은품 품목명
B박스수량발송 수량 (기본값: 1)
C받는분 성명 *필수택배 수령인 이름
D받는분 전화번호 *필수수령인 휴대폰 번호 (출고완료 매칭 기준)
E받는분 주소 *필수배송 주소 (전체 주소)
F배송메시지배송 시 전달 메시지
G쇼핑몰구매한 쇼핑몰명
H주문번호쇼핑몰 주문번호 (중복 방지 기준)
I아이디쇼핑몰 구매자 아이디
J구입일제품 구입일 (YYYY-MM-DD)
K제품명구입한 제품명
L메모기타 메모
N관리자 메모내부 관리자 메모

🚚 CJ택배 배송완료 엑셀 (출고완료 처리용)

CJ택배 사이트에서 다운로드하는 발송고객_일별_배달상세 파일을 그대로 사용합니다.

열 항목명 설명
H운송장번호시스템이 자동으로 읽어 등록합니다
V받는분 전화번호이 번호로 요청 리스트와 자동 매칭합니다
주의사항

주의사항

!
전화번호 형식 통일

출고완료 처리는 전화번호로 자동 매칭됩니다. 요청 리스트와 CJ택배 엑셀의 전화번호 형식이 달라도 자동으로 처리되지만, 번호 자체가 다르면 매칭되지 않습니다.

!
협찬/샘플: 팀장 승인 전에는 출고 처리 불가

요청 리스트에 올라온 건은 반드시 팀장 승인을 받아야 출고요청서 다운로드 및 출고완료 처리가 가능합니다.

!
포토이벤트: 주문번호 중복 주의

동일한 주문번호로 재업로드 시 자동으로 건너뜁니다. 수정이 필요한 경우 기존 건을 삭제 후 재업로드하거나 상세보기에서 직접 수정해 주세요.
